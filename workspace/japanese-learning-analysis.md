## 1. 개요 및 분석 배경

본 보고서는 **「釜山だより (부산 다요리)」** 서비스에서 제공하는 일본어 교육 콘텐츠의 교육적 완성도와 학습자 경험을 전문 일본어 강사의 시각에서 분석하고, 특히 **"일본어를 완전히 모르는 왕초보(Lv.0)부터 실전 회화(Lv.3), 심화 독해(Lv.4 레터)까지 이어지는 체계적인 레벨링 시스템"**을 구축하기 위한 청사진을 제시합니다.

## 3. 핵심 당면 과제: 체계적인 레벨링(Leveling) 부재

### ⚠️ 현재 발생하는 학습자 문제점
1. **왕초보(노베이스) 학습자의 진입 불가**:
   - 현재 콘텐츠는 최소 히라가나/가타카나와 기본 문형을 안다는 전제하에 작성되어 있어, 일본어를 전혀 모르는 학습자는 첫 화면부터 한자와 일본어 문장에 가로막혀 학습을 포기하게 됨.
2. **난이도 혼재로 인한 피로도**:
   - 예컨대 Day 1 레슨의 문법은 초중급 수준인데, 어휘에는 N2급 단어(`別添え`, `混雑時`)가 혼재되어 있어 본인의 현재 실력에 맞는 체계적인 단계적 성취감을 느끼기 어려움.

## 4. [제안] 왕초보(Lv.0)부터 시작하는 4+1단계 실전 레벨링 체계

일본어를 전혀 모르는 완전 초보자부터 자연스러운 원어민 표현을 구사하고 싶은 학습자까지 아우르는 맞춤형 로드맵입니다.

```
[Lv.0 입문 (왕초보)] ──▶ [Lv.1 초급 (N5~N4)] ──▶ [Lv.2 중급 (N3)] ──▶ [Lv.3 실전 (N2)] ──▶ [Lv.4 심화 (레터 원문 독해)]
 소리 & 한글발음           기본 패턴 & 여행회화      자연스러운 부탁 & 감정    원어민 뉘앙스 & 미각      부산 로컬 편지 읽기
```

### 단계별 상세 교육 설계 기준

| 레벨 | 대상 학습자 | 표기 원칙 & 교수법 | 문법 및 어휘 기준 | 대표 표현 예시 |
| :--- | :--- | :--- | :--- | :--- |
| **Lv.0 입문**<br>*(완전 노베이스)* | **글자를 전혀 모르는 왕초보**<br>(히라가나/한자 부담 없이 바로 말하고 싶은 학습자) | • **한글 독음(발음) 100% 필수 병기**<br>• 한자 완전 배제 (히라가나 위주)<br>• 문법 분석 지양, **'통문장 소리 암기'** | • 인사, 감사, 거절, 생존 한마디<br>• 만능 키워드 10~15개<br>• `〜ください (주세요)`<br>• `〜はどこですか (어디예요?)` | • `すみません [스미마센]` (저기요/죄송합니다)<br>• `これ ください [코레 쿠다사이]` (이거 주세요)<br>• `だいじょうぶです [다이죠-부데스]` (괜찮아요)<br>• `いくらですか？ [이쿠라데스카]` (얼마예요?) |
| **Lv.1 초급**<br>*(N5~N4 수준)* | 히라가나를 읽을 수 있고, 기본 어순과 조사를 익히기 시작한 단계 | • 모든 한자에 **루비(후리가나)** 병기<br>• 짧고 명료한 2턴 대화문<br>• 직관적인 한국어 번역 | • 기본 동사/형용사 활용 (`ます`, `て형`)<br>• 의문형, 허가/금지 표현<br>• 기초 상용 어휘 (음식, 숫자, 방향) | • `これを おねがいします` (이걸로 부탁합니다)<br>• `カードは つかえますか？` (카드 사용할 수 있나요?)<br>• `トイレは どこですか？` (화장실은 어디인가요?) |
| **Lv.2 중급**<br>*(N3 수준)* | 여행 회화가 가능하며 일상에서 자연스럽고 공손한 소통을 원하는 학습자 | • 필수 한자 노출 + 후리가나<br>• 2~3턴의 상황 대화<br>• 문화적 배경 팁 제공 | • 완곡한 배려형 의뢰 (`〜でお願できますか`)<br>• 수수동사 (`〜ていただく / くださる`)<br>• 조건형 (`〜たら / 〜なら`) | • `タテギ抜きで お願いできますか？`<br>• `別々で 会計していただけますか？`<br>• `辛くしないで もらえますか？` |
| **Lv.3 실전**<br>*(N2 수준)* | 교과서 일본어를 탈피해 현지 원어민 특유의 감각적 묘사를 배우고 싶은 학습자 | • 한자 중심 표기 (어려운 한자만 루비)<br>• 감각어, 관용구, 비즈니스/격식 매너 | • 식감/미각의 미묘한 차이 (`コクがある`, `さっぱり`)<br>• 화용론적 매너 (피크타임 배려 등)<br>• 복합동사, 유의어 뉘앙스 비교 | • `脂っこくなくて、豚骨のコクがしっかりある`<br>• `混雑時は まとめての お支払いを お願いしております` |
| **Lv.4 심화**<br>*(레터 연계)* | 현지인 수준의 긴 호흡의 글을 읽고 작문/소통하고 싶은 상급자 | • **부산 로컬 레터 원문 읽기**<br>• 일본인 독자와의 첨삭 교류 | • 에세이 수필체, 생생한 로컬 묘사<br>• 부산 사투리와 일본어의 문화적 대조 | • 부산 맛집·골목길 일본어 아티클 본문 전체 독해 및 표현 아카이빙 |

## 5. 시스템 및 코드베이스 구현 가이드

### 1) 데이터 타입 확장 (`src/types/index.ts`)
```typescript
// 레벨 타입 정의 (Lv.0 ~ Lv.3)
export type LessonLevel = 'starter' | 'beginner' | 'intermediate' | 'advanced';
// starter: Lv.0 (완전초보) | beginner: Lv.1 (초급 N5-N4) | intermediate: Lv.2 (중급 N3) | advanced: Lv.3 (실전 N2)

export interface DailyLesson {
  id: string;
  level?: LessonLevel;       // 난이도 필드 추가
  pronunciationKorean?: string; // Lv.0용 한글 독음 필드 (예: "스미마센, 코레 쿠다사이")
  // ... 기존 dialogue, grammar, vocabulary 등
}
```

### 2) AI 레슨 생성 프롬프트 규칙 세분화 (`src/lib/ai/workflow.ts`)
사용자가 선택한 레벨에 따라 Gemini 모델에 차별화된 프롬프트 전달:
* **`starter (Lv.0)` 생성 시**:
  * "한자는 일체 쓰지 말고 히라가나로만 작성하세요."
  * "반드시 `pronunciationKorean`(한글 소리 표기)을 포함하세요."
  * "문법 설명은 생략하고 '소리 내어 따라 말하는 패턴'으로만 작성하세요."
* **`beginner (Lv.1)` 생성 시**:
  * "N5~N4 수준의 기본 문형, 모든 한자에 후리가나 표기, 직관적인 일상 어휘 위주."
* **`intermediate / advanced (Lv.2~Lv.3)` 생성 시**:
  * "정중한 배려 표현, 현지인의 뉘앙스 차이(`nuanceTip`), 미각/감정 묘사 집중."

### 3) UI/UX 개선 방안
1. **홈 화면 레벨 선택 탭 / AI 생성 바**:
   * `[Lv.0 왕초보]` `[Lv.1 초급]` `[Lv.2 중급]` `[Lv.3 실전]` 칩(Chip)을 상단에 제공하여 한 번의 탭으로 학습자의 눈높이에 맞춤 전환.
2. **Lv.0 전용 대형 한글 발음 카드 모드**:
   * Lv.0 카드에서는 일본어 글자 밑에 **굵은 한글 발음**(`[코레 쿠다사이]`)을 시각적으로 강조하여 글자를 몰라도 즉시 입으로 발화할 수 있도록 지원.
3. **단어장(Voca) 레벨 필터링**:
   * `Lv.0 생존 단어`, `Lv.1 기초 단어`, `Lv.2 실전 단어`로 필터링하여 복습 부담 완화.

## 6. 결론

「부산 다요리」는 **일본인을 향한 따뜻한 부산 소개(Letters)**를 축으로 삼고, 그 이면에서 **한국인 학습자가 왕초보(Lv.0)부터 시작해 실전 회화(Lv.1~3)를 거쳐 레터 원문을 유창하게 읽고 쓸 수 있는(Lv.4) 단계적 성장 사다리**를 제공할 때 완성됩니다.

Lv.0(노베이스)의 도입은 일본어 진입 장벽을 완전히 허물어 플랫폼의 사용자 층을 대폭 확장시키는 결정적인 전환점이 될 것입니다.
