## 1. 개요 및 분석 배경

학습자가 **Lv.1 초급 Unit 3 (지하철역과 길 찾기)** 학습 중 다음 문제를 제기함:
> *"빨간색 박스의 unit의 문장을 무작정 외우려고 하니까 잘 외어지지가 않아. 등장하는 문장들에 포함된 용어들이 유사하게 느껴져서 헷갈려. 문장을 구성하는 동일한 단어와 조사들이 문장들에 포함되어 있어서 인 것 같아."*

본 보고서는 학습자가 겪은 암기 실패의 **학습 심리학 및 인지언어학적 원인**을 진단하고, 이를 유발한 **시스템 아키텍처 상의 데이터 결함 원인**을 분석하며, **전체 커리큘럼(Lv.0 ~ Lv.3)에 걸친 전수조사 결과 및 개선 조치**를 기록합니다.

## 2. 학습자 인지 및 교육학적 문제 분석

### 2.1. 단어와 조사의 '미분해' (형태소 경계선 상실)
- **현상:** 관련 단어장에 단어가 아닌 조사까지 붙은 `駅は`가 단어로 등록되고, 뜻과 발음도 문장 전체(`えきは どちらですか？` / `역은 어느 쪽인가요?`)로 기계적 매핑됨.
- **인지적 문제:**
  - 뇌는 언어를 습득할 때 **명사(어근) + 조사(문법 기능) + 서술어** 단위로 블록을 쪼개어 규칙을 구성함.
  - 조사가 단어의 일부로 묶여버리면 `駅(역)`이라는 독립 어휘가 뇌에 각인되지 않고, 다른 유닛의 `カードは`, `トイレは` 등과 조사가 뒤섞이며 극심한 기억 간섭(Memory Interference)을 초래함.

### 2.2. 대화 맥락(Context)의 오류로 인한 상황 연상 실패
- **현상:**
  - **나:** `駅は どちらですか？` (역은 어느 쪽인가요?)
  - **상대방:** `かしこまりました。どうぞ！` (알겠습니다. 여기 있습니다!)
- **인지적 문제:**
  - 길을 물었는데 물건을 건네주는 황당한 응답이 출력됨.
  - 언어는 '상황(장면)의 이미지'와 결합될 때 장기 기억으로 전환되는데, 문맥이 어긋나 시각적 상상이 불가능해지고 순수 텍스트만을 억지로 외우게 되어 암기 피로도가 급증함.

### 2.3. 모든 섹션의 도돌이표 (변형·확장의 부재)
- 키프레이즈, 롤플레잉 대화, 문법 설명, 단어장까지 화면 전체가 토씨 하나 다르지 않은 동일 문장(`駅は どちらですか？`)으로만 구성됨.
- 방향 안내 표현(`あちらです`, `まっすぐ`)이나 장소 교체 패턴(`トイレは`, `コンビニは`) 같은 **대체 연습(Substitution Drill)**이 없어 뇌의 시각적 자극이 둔화되고 암기 난이도가 비정상적으로 높아짐.

## 3. 시스템 아키텍처 원인 분석

### 3.1. 임시 대체 템플릿(Fallback Mechanism) 동작
- [curriculumData.ts](file:///c:/Users/dandycode/Documents/GitHub/busan-dayori/src/lib/curriculum/curriculumData.ts) 내 `getLessonByIdFromCurriculum` 함수는 해당 유닛에 정식 `lessonData` 객체가 없을 경우, 아래와 같이 기계적으로 데이터를 자동 생성하도록 되어 있었음:
  ```typescript
  // lessonData가 없는 유닛을 위한 완성형 대체 레슨 (curriculumData.ts:772-816)
  dialogue: [
    { speaker: '나', japanese: u.keyPhrase, korean: u.keyPhraseKorean, ... },
    { speaker: '상대방', japanese: 'かしこまりました。どうぞ！', korean: '알겠습니다. 여기 있습니다!', ... } // ⚠️ 고정 더미 응답
  ],
  vocabulary: [
    {
      id: `${u.id}-v1`,
      kanji: u.keyPhrase.split(' ')[0] || u.keyPhrase, // ⚠️ 단순 공백 분리로 인해 '駅は' 가 단어로 추출됨
      reading: kanaReading,                            // ⚠️ 전체 문장 읽기가 들어감
      meaning: u.keyPhraseKorean,                      // ⚠️ 전체 문장 뜻이 들어감
      partOfSpeech: '표현'
    }
  ]
  ```
- 이로 인해 `lessonData`가 누락된 유닛은 예외 없이 엉뚱한 대화와 뭉개진 단어장으로 노출되는 구조적 결함이 발생함.

### 4.2. 조사 요약 및 시사점
1. **Lv.0 (입문 5개 유닛):** 대화 3턴, 단어 분해, 꿀팁 문법이 완벽하게 내장되어 최상의 학습 경험 유지 중.
2. **Lv.1 (초급 3개 유닛):** Unit 2, Unit 3의 `lessonData` 누락을 이번 작업으로 완전히 해소하여 초급 전체가 완성됨.
3. **Lv.2 (중급 2개 유닛) & Lv.3 Unit 1:** Supabase DB에는 고품질 데이터가 있으나 정적 코드에 `lessonData`가 없어, 네트워크나 로딩 시점에 따라 Fallback 템플릿으로 빠질 위험이 존재함.
4. **Lv.3 Unit 2 (`advanced-2`):** DB와 코드 양쪽 모두에 데이터가 존재하지 않아, 학습자가 열람할 경우 무조건 Fallback(더미 대화 및 단어 깨짐)이 노출되는 상태임.

## 5. 완료된 개선 조치 (Lv.1 초급 유닛 보강)

### [Unit 3: 지하철역과 길 찾기 (`beginner-3`)]
- **실전 대화 개선:**
  - 나: `すみません、駅は どちらですか？` (실례합니다, 역은 어느 쪽인가요?)
  - 행인: `あちらです。まっすぐ 行ってください。` (저쪽입니다. 곧장(쭉) 가세요.)
  - 나: `ありがとうございます！` (감사합니다!)
- **단어 분해 등록:**
  - `駅` (えき / 역 [명사])
  - `どちら` (어느 쪽, 어디 [대명사])
  - `あちら` (저쪽, 저편 [대명사])
  - `まっすぐ` (곧장, 똑바로 [부사])
- **문법 공식화:** `[장소] + は + どちらですか？` 패턴 정의 및 `どこ`와의 격식 차이 해설 제공.

### [Unit 2: 결제 수단 묻기 (`beginner-2`)]
- **실전 대화 개선:**
  - 나: `すみません、カードは 使えますか？` (저기요, 카드 사용 가능한가요?)
  - 점원: `はい、使えますよ。どうぞ！` (네, 사용 가능합니다. 이쪽으로 주세요!)
  - 나: `これで お願いします。` (이걸로 부탁드립니다.)
- **단어 분해 등록:**
  - `カード` (카드 [명사])
  - `使える` (つかえる / 사용할 수 있다 [동사])
  - `現金` (げんきん / 현금 [명사])
- **문법 공식화:** `[결제 수단] + は + 使えますか？` 패턴 정의 및 일본 현금 문화 뉘앙스 팁 수록.

## 6. 향후 권장 과제

1. **Lv.2 중급 (`intermediate-1`, `intermediate-2`) 정적 데이터 동기화:**
   - DB에 존재하는 완성형 레슨을 `curriculumData.ts`의 `lessonData`로 복사 내장하여 로딩 속도 향상 및 Fallback 원천 차단.
2. **Lv.3 실전 (`advanced-1`, `advanced-2`) 정식 데이터 구축:**
   - DB의 `advanced-1` 데이터를 정적 동기화하고, 완전히 누락된 `advanced-2`("혼잡 시 일괄 결제 및 가게 에티켓")의 정식 3단계 대화, 분해 어휘, 문법 설명을 신규 작성하여 반영.
3. **Fallback 로직 안전성 강화:**
   - `getLessonByIdFromCurriculum`의 임시 단어 분할 로직(`split(' ')[0]`)을 조사(`は`, `が`, `を`) 제거 필터링을 거치도록 보완하여, 향후 신규 유닛 등록 시에도 단어 깨짐 현상 예방.
